New `@fluixi/create` package — scaffold a Fluixi app with `npm create @fluixi <dir>`
(or `pnpm create @fluixi`). Copies a minimal `@fluixi/start` app template (SSR + file
routing + hydration: `app.tsx`, server/client entries, `src/routes/`, `fluixi.config.ts`)
and sets the package name. Replaces the broken `kettle-generate` scaffolding.
