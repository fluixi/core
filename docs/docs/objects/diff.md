# Object Difference Utilities

The Object Difference (diff) module provides utilities for comparing JavaScript objects and detecting changes between them. These utilities are particularly useful for change tracking, state management, and optimizing updates in applications.

## Core Functions

### `diffObject(oldObj, newObj, options?)`

Compares two objects and returns an object containing only the changed values.

This function performs a deep comparison between two objects and generates a result object that contains only the properties that have changed. It can detect added, modified, and deleted properties, with options to customize the comparison behavior.

#### Parameters

- `oldObj: object` - The original object (baseline for comparison)
- `newObj: object` - The new object to compare against the original
- `options?: DiffOptions` - Optional configuration settings

#### Options

- `includeDeleted?: boolean` - Whether to include properties that exist in oldObj but not in newObj (default: false)
- `includeAdded?: boolean` - Whether to include properties that exist in newObj but not in oldObj (default: true)
- `deepArrayComparison?: boolean` - Whether to compare arrays by deep equality instead of reference (default: true)
- `equalityFn?: (a: any, b: any) => boolean` - Custom equality function for comparing values
- `preserveStructure?: boolean` - Whether to preserve the full object structure with undefined for unchanged values (default: false)

#### Returns

A `DiffResult` object containing:
- `diff`: The object containing only the changed values
- `added`: Array of paths that were added
- `deleted`: Array of paths that were deleted
- `modified`: Array of paths that were modified
- `hasChanges`: Boolean indicating whether any changes were detected

#### Examples

**Basic comparison**

```ts
const oldObj = { name: 'Alice', age: 30, settings: { theme: 'light' } };
const newObj = { name: 'Alice', age: 31, settings: { theme: 'dark' } };

const result = diffObject(oldObj, newObj);
// result.diff = { age: 31, settings: { theme: 'dark' } }
// result.hasChanges = true
// result.modified = ['age', 'settings.theme']
```

**Including deleted properties**

```ts
const oldObj = { name: 'Alice', age: 30, role: 'admin' };
const newObj = { name: 'Alice', age: 30 };

const result = diffObject(oldObj, newObj, { includeDeleted: true });
// result.diff = { role: undefined }
// result.deleted = ['role']
```

**Preserving structure**

```ts
const oldObj = { user: { name: 'Alice', profile: { age: 30, role: 'admin' } } };
const newObj = { user: { name: 'Alice', profile: { age: 31, role: 'admin' } } };

const result = diffObject(oldObj, newObj, { preserveStructure: true });
// result.diff = { user: { profile: { age: 31 } } }
```

### `applyDiff(obj, diff)`

Applies a diff object to an existing object to update it.

This function takes a diff object (generated by `diffObject`) and applies the changes to an existing object, effectively updating it to match the new state that the diff represents.

#### Parameters

- `obj: object` - The object to apply changes to
- `diff: object` - The diff object containing changes to apply

#### Returns

The updated object (same reference as input object).

#### Examples

```ts
const obj = { name: 'Alice', age: 30, settings: { theme: 'light' } };
const diff = { age: 31, settings: { theme: 'dark' } };

applyDiff(obj, diff);
// obj is now: { name: 'Alice', age: 31, settings: { theme: 'dark' } }
```

### `trackChanges(obj)`

Creates a change tracker for an object to monitor modifications.

This function sets up tracking on an object to detect changes made to it. It returns a proxy that wraps the original object and a function to get the changes that have been made.

#### Parameters

- `obj: object` - The object to track changes for

#### Returns

An object containing:
- `proxy`: A proxy that tracks changes to the original object
- `getChanges(): DiffResult` - A function that returns the changes made to the object

#### Examples

```ts
const user = { name: 'Alice', settings: { theme: 'light' } };
const { proxy, getChanges } = trackChanges(user);

// Make some changes through the proxy
proxy.name = 'Bob';
proxy.settings.theme = 'dark';
proxy.role = 'admin';

// Get the changes
const changes = getChanges();
// changes.diff = { name: 'Bob', settings: { theme: 'dark' }, role: 'admin' }
// changes.modified = ['name', 'settings.theme']
// changes.added = ['role']
```

## Advanced Functions

### `mergeWithDiff(target, source, diffOptions?)`

Merges two objects and returns both the merged result and a diff of what changed.

This function combines the functionality of object merging and diffing to provide both the merged object and a detailed record of what changed during the merge.

#### Parameters

- `target: object` - The target object to merge into
- `source: object` - The source object to merge from
- `diffOptions?: DiffOptions` - Options for the diff operation

#### Returns

An object containing:
- `result`: The merged object
- `diff`: The diff result showing changes that were made

#### Examples

```ts
const target = { name: 'Alice', settings: { theme: 'light', notifications: true } };
const source = { age: 30, settings: { theme: 'dark' } };

const { result, diff } = mergeWithDiff(target, source);
// result = { name: 'Alice', age: 30, settings: { theme: 'dark', notifications: true } }
// diff.added = ['age']
// diff.modified = ['settings.theme']
```

## Use Cases

- **State Management** - Track changes in application state to optimize rendering
- **Form Handling** - Detect which fields have been modified from their initial values
- **API Updates** - Send only the changed data to APIs instead of complete objects
- **Undo/Redo Functionality** - Store diffs to implement undo/redo features efficiently
- **Change Logs** - Generate logs or audit trails of changes made to data
- **Optimistic UI** - Apply changes optimistically while waiting for server confirmation

## Performance Considerations

- The diff operation requires deep traversal of objects, which can be expensive for very large objects
- When working with large objects, consider setting `deepArrayComparison: false` if arrays can be compared by reference
- For nested objects with minimal changes, using `preserveStructure: false` (the default) results in smaller diff objects
