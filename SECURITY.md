# Security policy

## Supported versions

Fluixi is in alpha. Fixes land in the latest `alpha` release only.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: on the [Security tab](https://github.com/fluixi/core/security), choose **Report a vulnerability**. Include the affected package and version, what an attacker can do, and steps or code to reproduce it.

You can expect a first reply within a week. Once a fix is released, the advisory is published with credit to the reporter, unless you prefer to stay anonymous.
