package:  @fluixi/cdn
audience: someone loading the framework from a script tag, with no bundler
one-line: the import maps a page needs, already generated
measured: min is 15 entries, templates adds 3, full is 19
verified: both forms below were run in a browser
do-not-claim: that an import map can be referenced by url. `<script type="importmap"
          src="...">` was specified and never shipped — Chrome 151 fails on it with
          "Failed to resolve module specifier". Do not show it.
          do not claim this replaces a build: the compiled path is smaller.
structure: three short sections, no headings beyond the ones named.
  1. what it is: a browser resolves bare specifiers only through an import map and
     never reads package.json, so every transitive subpath has to be listed. These
     files list them, pinned to the version of this package.
  2. "The maps" — a list, one line each:
     min.json — @fluixi/core, @fluixi/dom, @fluixi/utils and the graph behind them.
       Enough to write components by hand; `@fluixi/core` re-exports most of the dom
       and reactive surface, so one import covers most of it.
     templates.json — adds compiling html`` in the page. Load it with min.json.
     full.json — everything a browser can use, in one file.
  3. "Using one" — say the contents go inline, then this block VERBATIM:
```html
<script type="importmap">
  { "imports": { "…": "paste the contents of min.json here" } }
</script>
<script type="module">
  import { render, signal } from '@fluixi/core';
</script>
```
     then: a page that would rather not paste can fetch the file and add the map
     itself, which works because a map may be added before the first module loads —
     with this block VERBATIM:
```html
<script type="module">
  const map = await fetch('https://unpkg.com/@fluixi/cdn/dist/min.json').then((r) => r.json());
  const tag = document.createElement('script');
  tag.type = 'importmap';
  tag.textContent = JSON.stringify(map);
  document.head.appendChild(tag);

  const { render, signal } = await import('@fluixi/core');
</script>
```
     close with: several maps in one page need Chromium 133 or newer, and full.json
     is the single-file way round that.
