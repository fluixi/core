files:  packages/core/src/lib/render/component.ts,
        packages/core/src/lib/render/lifecycle-server.spec.ts
what:   onMount and useEffect no longer run their callback on the server. Both
        scheduled their flush on a microtask, which lands after renderToString has
        already returned — a component calling either during prerender reached for
        `document` and threw.
why:    a component rendered to a string is never mounted, and there is no
        teardown to run a cleanup, so neither belongs on the server. Solid and
        React already treat them this way.
