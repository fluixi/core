files:  packages/devtools/src/source.ts (new), instrument.ts, graph-view.ts, index.ts,
        instrument.spec.ts, README.md
what:   a graph node carries an optional source — file, line and column — and a memo wrapping
        a component reports itself as a component, with the component's name and the place it
        was declared. Effects pulse when they re-run, and a DOM value reads as `<div>`.
why:    devtools owns the graph, so it owns this too: the compiler marks a creation site, the
        instrumented primitive takes the mark, and the node keeps it. A renderer reads
        node.source and needs no compiler, no source file and no ast. There is one place a
        mark is taken — the function every tracked primitive already goes through — so the
        node's identity is still the graph's own.
        an effect has no value to read, so nothing ever marked it as having done something;
        it pulses on its run count now.
        the compiler wraps every component in a memo, and that memo showed as `m5` holding
        `[object HTMLDivElement]`. It reports the name the runtime stamped on what the
        component returned, and where that component was declared. Two components sharing a
        name are reported without a location rather than with the wrong one.
verify: sixteen specs, covering the metadata surviving updates and going away with its node
