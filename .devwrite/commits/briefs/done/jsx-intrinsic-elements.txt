     elements in it and every `<div>` in an application was "Property 'div' does not exist".

  3. Element stays an alias. What the dom can insert is a union — a node, a string, a list, a
     function returning one — and an interface cannot extend a union. Declaring it as one
     made every nested element unassignable to a children typed ComponentChild.
